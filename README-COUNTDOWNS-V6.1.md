Echo Calendar V6.1 — Olivia Countdowns

1. Run supabase/olivia_countdowns_v6_1.sql in Supabase SQL Editor.
2. Replace the GitHub repository with this entire package, preserving its folder structure.
3. Netlify builds via npm run build.
4. Parent Manage > Events > Add/Edit: enable Add to Countdown; optional end date for multiday events.
5. Olivia > My Week > Countdowns.

Countdowns apply to native calendar_events; imported read-only iCloud feed events are not directly editable by this toggle.
